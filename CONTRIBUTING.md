# Contributing

Use Node.js 22 or newer, install with `npm ci`, and run `npm test` and `npm run test:coverage`. Keep tests isolated from real workspace data and paid API requests. For UI changes, run the relevant Electron `test:*` script against a local server and check both themes.

Keep credentials, local configuration, PDFs and research data out of commits. Describe the behavior changed, validation performed and any limitations in pull requests. A license must be selected by the repository owner before distributing the project as open-source software.
